# Plan: Embed Whisper Model Locally (No API Calls)

## Current State

The app uses `Speech2TextServiceController.ts` which currently:
- **ACTIVE_PROVIDER = 'custom'** → calls `https://cisckids2026-marungko-whisperapi.hf.space/transcribe`
- Previously used HuggingFace Inference API (`whisper` endpoint)
- Records audio via `react-native-audio-record` (16kHz, mono WAV)

## Feasibility Assessment

**YES, it is doable.** Options for on-device Whisper:

| Option | Model Size | Accuracy | Mobile Support | Notes |
|--------|-----------|----------|----------------|-------|
| **react-native-whisper** | 75-300MB | High | Android/iOS | Uses whisper.cpp, native bindings |
| **whisper.cpp** | 75-300MB | Good | Android/iOS | Requires native module setup |
| **ONNX Runtime Mobile** | 100-500MB | High | Android/iOS | More complex integration |
| **TensorFlow Lite** | 100-500MB | Good | Android/iOS | Requires model conversion |

## Recommended Approach: react-native-whisper (whisper.cpp)

**Rationale:**
- Already used in production by other React Native apps
- Supports Tagalog/Filipino (multilingual model)
- Tiny model (~75MB) for basic accuracy, Base model (~140MB) for better accuracy
- Works offline, no internet permission needed after setup

## Implementation Steps

### Phase 1: Setup & Dependencies

1. **Install react-native-whisper**
   ```bash
   npm install react-native-whisper
   # OR use the community-maintained fork:
   npm install @adm-toolkit/react-native-whisper
   ```

2. **Download Whisper model files**
   - Place `.bin` model files in `android/app/src/main/assets/models/`
   - Models: `ggml-tiny.bin` (75MB), `ggml-base.bin` (140MB), `ggml-small.bin` (470MB)
   - Source: https://huggingface.co/ggerganov/whisper.cpp

3. **Update Android build.gradle**
   ```gradle
   android {
       // Increase heap size for model processing
       dexOptions {
           javaMaxHeapSize "4g"
       }
   }
   ```

### Phase 2: Native Module Integration

4. **Create Native Module Interface** (`Speech2TextServiceController.ts`)
   - Add new provider: `'local'`
   - Implement `transcribeWithLocalWhisper()` function
   - Handle model loading state

5. **Update Transcription Flow**
   ```typescript
   const ACTIVE_PROVIDER = 'local' as Provider;
   
   const transcribeWithLocalWhisper = useCallback(async (
     audioFilePath: string,
     options: TranscriptionOptions,
   ): Promise<string> => {
     // Initialize Whisper with model path
     await Whisper.initModel('models/ggml-base.bin');
     
     // Transcribe audio
     const result = await Whisper.transcribe(audioFilePath, {
       language: 'fil',  // Filipino/Tagalog
       task: 'transcribe',
     });
     
     return cleanTranscript(result.text);
   }, []);
   ```

### Phase 3: File Size Optimization

6. **Model Selection Strategy**
   - **Initial APK**: Include `ggml-tiny.bin` (75MB) for offline-first
   - **Optional download**: Larger models downloaded on first launch (if needed)
   - **App bundle**: Use Play Feature Delivery for model splits

7. **Audio Preprocessing**
   - Current: 16kHz mono WAV (already compatible)
   - No changes needed to `AudioRecordingController.ts`

### Phase 4: Testing & Validation

8. **Test scenarios**
   - Cold start (model first load)
   - Memory usage during transcription
   - Tagalog/English word recognition accuracy
   - Background transcription (if needed)

9. **Fallback mechanism**
   - Keep `getSimulatedResponse` for development
   - Optionally keep API fallback if local fails

## Estimated Impact

| Metric | Current (API) | Local Whisper |
|--------|---------------|---------------|
| App size | ~50MB + model download | +75-150MB |
| Latency | 1-5s (network) + 20s cold start | 2-10s (device dependent) |
| Internet required | Yes | No |
| Offline capability | No | Yes |
| Monthly cost | API usage fees | None |

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Large APK size | Use Play Feature Delivery for model |
| Memory constraints | Test on low-end devices, use tiny model |
| Tagalog accuracy | Validate with Filipino text samples |
| iOS support | Verify library compatibility or use Expo Modules |
