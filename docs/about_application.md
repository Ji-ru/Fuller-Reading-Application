## ✨ About the App

CISC Kids is a mobile reading assessment platform designed for **Grade 1–3 students**. It uses **speech recognition** to evaluate oral reading fluency, detect miscues, and track reading progress over time — giving teachers and students actionable insights in real time.

The app supports three reading modes — **word pronunciation** and **passage reading** — each with automatic accuracy scoring and miscue analysis (substitution, omission, insertion, and repetition).

### Feature Highlights

| Feature             | Description                                                    |
|---------------------|----------------------------------------------------------------|
| **Oral Fluency**    | Evaluates how accurately and fluently a student reads aloud   |
| **Miscue Analysis** | Detects reading errors: substitution, omission, insertion, repetition |
| **Progress Tracking**| Monitors student reading improvement over time               |
| **Grade 1–3**       | Tailored content and assessment for early grade learners      |
| **English Language**| Focused on English reading comprehension and pronunciation    |

### Model Description

Nova-3 is an advanced speech-to-text model designed for highly accurate, fast, and reliable transcription. It is optimized for real-time speech recognition and can capture spoken words with strong contextual awareness, making it well suited for evaluating young learners' reading fluency, pronunciation, and oral reading accuracy.

### Model Capabilities

- **Real-time** — Low-latency transcription during live reading sessions
- **High accuracy** — Precise word detection even for young or developing readers
- **Context-aware** — Understands spoken language with strong contextual understanding
