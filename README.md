# Reading Assessment & Fluency App

An educational web application tailored for students in Grades 1 to 3, designed to help assess and evaluate their reading pronunciation and fluency. This platform serves as a comprehensive tool for both teachers and students, ensuring early learners get the attention and intervention they need in their reading journey.

## Overview

The application bridges the gap between classroom teaching and individualized reading assessment. It allows teachers to create a structured environment where they can actively monitor their students' progress. By evaluating reading fluency and pronunciation, educators can quickly identify struggling students and provide the necessary intervention. 

## Key Features

### Teacher Account
- **Class Management:** Create and organize classes with ease.
- **Simple Onboarding:** Invite students to join a class using a unique, easy-to-share **class code**.
- **Progress Monitoring:** Track the reading journey of each student over time.
- **Assess & Evaluate:** Monitor reading pronunciation and fluency through targeted assessments.
- **Targeted Intervention:** Easily identify struggling students who require extra attention and data-driven intervention.
- **Performance Analytics:** View detailed progress reports for individual students and the entire class.

### Student Account (Grades 1-3)
- **Easy Access:** Join a class effortlessly using the teacher-provided class code.
- **Interactive Reading:** Engage in reading exercises designed specifically for 1st to 3rd graders.
- **Pronunciation Practice:** Practice reading aloud to improve pronunciation and fluency.
- **Engaging Experience:** A child-friendly interface that motivates students to continue their reading journey.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS (based on the project's layout)

## Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- npm, yarn, or pnpm

### Installation

1. Clone the repository and navigate to the client directory:
   ```bash
   cd client
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production

To build the application for production, run:
```bash
npm run build
```
